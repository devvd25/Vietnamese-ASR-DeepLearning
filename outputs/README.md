# Kết quả thực nghiệm

Chỉ các kết quả do lệnh trong `scripts/` thực sự sinh ra mới được đặt tại đây:

- `tables/`: JSON/CSV metric và thống kê dataset.
- `predictions/`: prediction/reference theo từng audio.
- `figures/`: biểu đồ từ log/metric thật.
- `reports/`: tóm tắt môi trường và lần chạy.

Không có file kết quả mẫu giả trong repository.
